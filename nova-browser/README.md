# NOVA Browser

متصفح ويب حقيقي لنظامي **Windows 10 / 11** بهوية بصرية مستقبلية: تبويبات زجاجية عائمة،
شريط عنوان ذكي، صفحة رئيسية حية بخلفيات تفاعلية، ومركز تحكم عائم — مبني على
**Electron + Chromium** لعرض صفحات الويب الحقيقية (عنصر `<webview>` بعملية عرض
منفصلة لكل تبويب — لا يستخدم iframe إطلاقًا).

---

## التشغيل والتطوير

### المتطلبات
- [Node.js](https://nodejs.org/) إصدار 18 أو أحدث
- Windows 10 / 11 (للبناء النهائي) — يعمل أيضًا على macOS/Linux أثناء التطوير

### التثبيت والتشغيل
```bash
npm install
npm start
```

### الاختبارات
```bash
npm test
```
تشمل اختبارات وحدة (Node.js Test Runner) لمنطق تطبيع عناوين شريط العنوان والبحث.

### بناء نسخة Windows القابلة للتثبيت (EXE)
```bash
npm run dist:win
```
ينتج في مجلد `release/`:
- مثبّت NSIS تفاعلي: `NOVA-Browser-1.0.0-nsis.exe`
- نسخة محمولة بلا تثبيت: `NOVA-Browser-1.0.0-portable.exe`

> بديل تلقائي: ارفع المشروع إلى GitHub وفعّل سير العمل الجاهز
> `.github/workflows/build-windows.yml` — سيبني ملفات EXE على خادم Windows
> ويرفعها كـ Artifact جاهز للتنزيل، وينشئ Release تلقائيًا عند دفع وسم مثل `v1.0.0`.

## الميزات المنفذة فعليًا

### التبويبات (العنصر المميز)
- تبويبات عائمة زجاجية مع مؤشر توهّج للتبويب النشط، ومؤشر تحميل حقيقي.
- حركة دخول انسيابية (Spring)، سحب وإفلات لإعادة الترتيب، إغلاق بالنقر الأوسط.
- **تثبيت التبويبات**، **مجموعات ملوّنة** (5 ألوان)، تكرار، إغلاق الأخرى — من قائمة النقر الأيمن على التبويب.
- استعادة تبويب مغلق (`Ctrl+Shift+T`)، واستعادة جلسة كاملة عند البدء.
- **تحميل كسول** للتبويبات المستعادة غير النشطة لتوفير الذاكرة.

### التصفح الحقيقي
- فتح أي موقع HTTP/HTTPS بمحرك Chromium كامل، مع رجوع/تقدّم/إعادة تحميل/إيقاف.
- روابط `target=_blank` و`window.open` تُفتح كتبويبات جديدة داخل NOVA.
- قائمة سياقية أصلية غنية للروابط والصور والنص المحدد والحقول (فتح في تبويب، حفظ صورة، بحث عن النص، فحص العنصر…).
- بحث داخل الصفحة (`Ctrl+F`) مع عدّاد نتائج وتنقّل، وتكبير/تصغير لكل تبويب (`Ctrl+ +/- /0`) مع شارة نسبة قابلة للنقر لإعادة التعيين.
- صفحات خطأ واضحة بالعربية (DNS، انقطاع الاتصال، مهلات، شهادات…) مع إعادة محاولة.
- مؤشر حالة اتصال: قفل آمن لـ HTTPS وتحذير لـ HTTP.

### شريط العنوان الذكي
- تحديد تلقائي للعنوان عند النقر، وتمييز بصري عند التركيز.
- اقتراحات حقيقية فورية من: الإشارات المرجعية + سجل التصفح + **اقتراحات محرك البحث المختار عبر API رسمية** (Google / DuckDuckGo / Bing).
- تنقّل كامل بلوحة المفاتيح (أسهم + Enter + Esc) ودعم `Ctrl+Enter` لإكمال www.‎.com.

### الصفحة الرئيسية والخلفيات التفاعلية
- دخول متسلسل أنيق: شعار عائم، ساعة وتاريخ، بحث، اختصارات قابلة للإضافة/الحذف (`Ctrl+نقر` يفتح في تبويب خلفي).
- خمس خلفيات: تدرّج متحرك، شبكة هندسية متحركة بـ Canvas (تتوقف تلقائيًا عند عدم الرؤية)، شفق هادئ، لون ثابت مخصص، **صورة من جهاز المستخدم**.
- كل التفضيلات تُحفظ محليًا وتُستعاد.

### مركز التحكم العائم
- سمة داكنة/فاتحة/تلقائية (تتبع النظام)، 5 ألوان تمييز، حجم واجهة قابل للضبط.
- تعطيل الرسوم المتحركة، **وضع منخفض استهلاك الموارد**، احترام إعداد `prefers-reduced-motion` في Windows.
- محرك بحث قابل للتبديل (Google / DuckDuckGo / Bing / Brave)، التحكم بالاقتراحات، استعادة الجلسة، تسجيل السجل.
- أقسام للإشارات المرجعية والسجل (بحث فوري + حذف فردي) والتنزيلات.

### التنزيلات الحقيقية
- تنزيل فعلي للملفات إلى مجلد «التنزيلات» مع منع الكتابة فوق الملفات، شريط تقدّم مباشر،
  إشعار عند الاكتمال، وزرّا «فتح» و«المجلد».

### الخصوصية والأمان
- `nodeIntegration` معطّل و`contextIsolation` + `sandbox` مفعّلة؛ صفحات الويب معزولة تمامًا عن النظام.
- إذن صريح من المستخدم (حوار نظامي) قبل الكاميرا/الميكروفون/الموقع/الإشعارات.
- أخطاء شهادات HTTPS لا تُتجاوز أبدًا.
- نوافذ متخفية (`Ctrl+Shift+N`) بقسم تخزين في الذاكرة فقط، دون سجل أو جلسة محفوظة.
- مسح السجل وبيانات المواقع والذاكرة المؤقتة بضغطة زر. **لا تتبّع ولا إرسال بيانات إطلاقًا.**

### اختصارات لوحة المفاتيح
`Ctrl+T/W/Shift+T` تبويبات · `Ctrl+Tab` تنقّل · `Ctrl+1..8` قفز لتبويب · `Ctrl+L` العنوان ·
`Ctrl+F` بحث · `Ctrl+D` إشارة · `Ctrl+H/J` سجل/تنزيلات · `Ctrl+R/F5` إعادة تحميل ·
`Ctrl+Shift+N` متخفٍ · `Alt+أسهم` رجوع/تقدّم · `F11` ملء الشاشة.
تعمل حتى عندما يكون التركيز داخل صفحة الويب (عبر قائمة تطبيق مخفية).

## بنية المشروع

```
nova-browser/
├─ package.json               # إعدادات Electron وelectron-builder (نسخة Windows)
├─ build/icon.png             # أيقونة التطبيق (1024×1024)
├─ scripts/make_icon.py       # سكربت إعادة توليد الأيقونة
├─ src/
│  ├─ main.js                 # العملية الرئيسية: نوافذ، تنزيلات، أذونات، قوائم سياق، اختصارات
│  ├─ preload.js              # جسر IPC آمن محدود (لواجهة NOVA فقط)
│  └─ renderer/
│     ├─ index.html           # هيكل الواجهة
│     ├─ styles.css           # الهوية البصرية والحركات
│     ├─ app.js               # إدارة التبويبات/الجلسات/الاقتراحات/الإعدادات
│     └─ url-utils.js         # منطق العناوين (قابل للاختبار)
├─ tests/url-utils.test.js    # اختبارات الوحدة
└─ .github/workflows/build-windows.yml   # بناء EXE تلقائي على Windows
```

## ملاحظات وحدود معروفة
- إضافات Chrome (Extensions) غير مدعومة في هذه النسخة (قيود `<webview>` في Electron).
- محتوى DRM مثل Netflix يحتاج بناء Chromium خاصًا بـ Widevine (CastLabs) غير مضمّن.
- كلمات المرور والملء التلقائي للبطاقات غير مدعومة حاليًا.
- عند فتح `src/renderer/index.html` في متصفح عادي تعمل الواجهة في «وضع معاينة» لاستعراض
  التصميم فقط — التصفح الحقيقي يعمل داخل تطبيق Electron (`npm start`).
